C. Una rama es una confirmación antigua, y HEAD es siempre la confirmación más reciente. [7]

A. Para prevenir que ciertos archivos sean subidos al repositorio remoto. [8]
B. Para indicar a Git qué archivos o patrones de archivos debe ignorar y no incluir en el control de versiones. [8]

2. ¿Qué acción realiza el comando git commit --amend? [9]
A. Crea una nueva confirmación que deshace los cambios de la última. [9]
B. Permite modificar el mensaje de la última confirmación o añadir/eliminar archivos de la misma. [9]
C. Combina las últimas dos confirmaciones en una sola. [9]
